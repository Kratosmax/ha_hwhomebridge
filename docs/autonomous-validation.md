原生更改先在独立进程、隔离网络中检查单台和批量接口及其他品类不变；
只定向部署所需文件，运行共享库使用同目录临时文件及原子替换。
不修改网关身份，不删除已有云端设备，不执行真实报警、自检、消音、喂食或断电测试。
远端提交、推送、发布仍不在本轮授权内。

停止结论限定为当前源、当前产品定义或已验证SDK的具体边界，
不把“没搜到”写成平台绝对不支持。每项留下源码位置、实际数据或官方定义、测试及结果。
若后来源增加了恢复状态、产品定义或云接口发生变化，相应停止结论须重新核验。

各项停止依据见 [兼容性结论](compatibility-limits.md)。本机原始证据包括官方定义和SHA256、
原始MIoT定义、HA设备清单、云设备及缓存读数、单设备注册结果和部署前备份。
